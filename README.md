# Interpreting transformer portfolios

Self-contained HTML slides for the Ulster University presentation on 14 October 2026.

The published site needs only `index.html`. All presentation assets are embedded in that file. The two literature links open DOI pages and therefore require an internet connection when followed.

For presenting, open `index.html` in Chrome. Use the arrow keys to move through the deck, `F` for full screen and `S` for speaker view.
